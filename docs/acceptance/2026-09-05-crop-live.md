# 裁剪即时反馈修正

松开鼠标时直接提交本地预览状态并居中适配，不再回退旧选区等待后台采集。重置裁剪也走同一即时反馈路径。后台仍校验源图坐标、更新实际裁剪并恢复原有监控。

提交带递增版本，旧回执无法覆盖新选区；切换监控任务会使之前版本失效。确认不会打断正在进行的下一次拖动。失败回执同步实际后台状态，Esc 或未改变范围的鼠标释放会正确恢复已确认状态。同一监控任务的后台修改串行处理，避免停止与启动流程重叠。

验证：87 项测试通过，Ruff 检查与格式检查通过。回归覆盖即时呈现、连续提交、迟到回执、任务切换、失败恢复及后台串行处理。

程序：`dist/crop-live/ScreenQQOCR/ScreenQQOCR.exe`。首次使用前退出旧版托盘进程，保留整个程序文件夹。
