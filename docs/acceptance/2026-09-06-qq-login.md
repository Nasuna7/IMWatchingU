# QQ 扫码登录修正 · 2026-09-06

本机运行中的打包版 NapCat 管理接口返回 `isLogin=false`、`isOffline=false`，具体错误为账号已登录、无法重复登录。旧界面把所有非空 `loginError` 都显示为“登录异常或二维码已过期”，未展示真实原因。此次只读取管理状态，未退出其他 QQ 会话、刷新用户二维码或发送消息。

修正内容：

- 显示 NapCat 的具体错误，并区分重复登录、过期和离线；二维码缺失或刷新中清除旧画面。
- 刷新请求和状态查询串行；RefreshQRcode 返回成功后继续等待二维码 URL 更新或明确的登录结果。
- 刷新最长等待 10 秒，超时给出生成失败提示；后续轮询也不重新展示已作废旧码。
- 刷新期间禁用按钮，避免重复刷新；恢复状态后允许重试。

根据 [NapCat 管理接口实现](https://github.com/NapNeko/NapCatQQ/blob/main/packages/napcat-webui-backend/src/api/QQLogin.ts)，刷新响应不包含新二维码，状态必须另行查询。本机 Shell 实现也确认二维码通过异步回调生成。
