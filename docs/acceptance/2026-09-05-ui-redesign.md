# 桌面 UI 重构验收 · 2026-09-05

采用 Gray / Amber 配色，将六页桌面应用接入统一主题和控件。监控页使用任务卡片、预览工作区、检测设置、最近识别与通知队列；QQ 页集中展示 Shell 启动与消息连接；规则编辑使用独立弹窗。保留现有 Presenter 信号、任务 ID、裁剪坐标、OCR、发送逻辑及 NapCat 进程退出逻辑。

自定义范围包含窗口标题栏、按钮、下拉弹层、输入框、数字步进、复选框、表格和表头、标签页、滚动条、工具提示、文本右键菜单、托盘菜单、规则导入弹窗、错误弹窗及非原生文件选择器。统一线性 SVG 图标，Qt 内置文件选择文字加载中文翻译。支持浅色、深色、跟随系统及减少动画；外观偏好通过应用设置保存。
