# 屏幕识别 → QQ 发送工具

网页启动的屏幕识别工具：持续监控屏幕上指定区域的中文文字，识别到设定的关键词后，
自动把识别结果粘贴发送到**本机 QQ 客户端当前打开的对话框**。全部数据在本机处理，不上传。

## 功能

- 🖥️ 浏览器截屏（`getDisplayMedia`，可选整屏 / 窗口 / 标签页；捕获帧率上限 15fps，可选**低分辨率捕获**模式缓解系统卡顿）
- ✂️ 拖拽选择识别区域（可随时清除改为全屏）
- 🔤 中文 OCR（双引擎可选：内置 Tesseract 快速本地识别 / **Windows 系统 OCR** 更贴近真实界面；模型本地缓存，离线可用）
- 🎯 关键词自动触发：每个关键词可单独设置**监控条件**（该关键词在识别文本中**出现 ≥N 次**才触发）与**定制发送内容**，独立冷却防刷屏；支持**保存/读取 keywords.txt** 持久化（格式：关键词|出现次数|消息）
- 📊 识别计数：每次识别显示「N 行 / M 字」，日志实时可见
- 🚨 色块闪烁识别（独立模块）：以 250ms 间隔采样识别区域色块颜色（红/白/橙），**连续 4 次采样颜色都发生变化**时触发**持续 3 秒**的报警音（按冷却间隔可重复触发）；内置**独立闪烁日志**（可不开关键词单独运行）
- 💬 QQ 自动发送：激活 QQ 窗口 → 剪贴板粘贴 → 回车发送（Enter / Ctrl+Enter 可选）；支持**文本**与**识别区域截图（PNG）**两种发送；可勾选「关键词命中时发送截图」
- 🧪 测试发送 / 测试发送截图 / 立即识别一次 / 实时日志

## 环境要求

- Windows 10/11
- Node.js（已安装的 v24 可用；任意 18+ 均可）
- Chrome 或 Edge 浏览器
- 本机 QQ 客户端（QQ NT / QQ 9.x）已安装、**已登录并正在运行**
- 首次初始化需联网（下载约 25MB 依赖），之后完全离线

## 安装（一次性）

```bat
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\setup.ps1
```

> 本机 PowerShell 5.1 的 schannel TLS 异常，初始化脚本统一用 Node(OpenSSL) 下载；
> 若 jsdelivr 不可达会自动改用 npm 方式。

## 启动

双击 **`start.bat`**，浏览器自动打开 `http://127.0.0.1:8765`。

（或手动：`node server.js`，可用环境变量 `PORT=8899` 改端口；`NO_AUTO_OPEN=1` 禁用自动开浏览器）

## 使用步骤

1. **先在本机 QQ 打开目标聊天对话框**（群或好友），确认输入框可输入。
2. 网页上点「开始截屏」，在系统弹窗中选择要监控的屏幕或窗口。
3. （可选）在预览画面上**拖拽**选择识别区域；不选则识别全屏。
4. 配置触发方式（可组合）：
   - **关键词触发**：在「识别设置」添加中文关键词，每个关键词可设置**监控条件**（该关键词出现 ≥N 次才触发，默认 1 次）与**定制发送内容**（可多个，出现即命中）；
   - **色块颜色识别**：在「④ 色块颜色识别」勾选启用，统计区域内非文字部分的红/白/橙像素数，取最多者为色块颜色，颜色变化时播放对应警告音（可单独使用，无需关键词）。建议把识别区域框在色块附近。
5. 在「QQ 发送设置」里核对：
   - **发送按键**：与 QQ 设置里的「发送消息」快捷键一致（默认 Enter）；
   - **QQ 窗口目标**：默认「自动」，自动优先选择当前聊天窗口；也可手动指定。
6. 点「开始监控」。关键词命中后网页倒计时（可关）并自动发到 QQ 当前对话框；颜色变化时播放警告音。
7. 建议先点「测试发送」验证链路，再正式监控。

## 常见问题

| 现象 | 处理 |
|---|---|
| 状态栏「QQ: 未运行」 | 先启动 QQ 并登录，等待几秒自动刷新；若持续显示，看日志面板的「状态检查」提示 |
| 「无法激活 QQ 窗口」 | 系统前台锁限制，先手动点击一下 QQ 窗口，或稍后再试 |
| 发送没进对话、进了别处 | 检查「QQ 窗口目标」下拉选中的窗口；发送前确保目标聊天已打开 |
| 按 Enter 没发送 / 变成换行 | 在 QQ 设置中核对「发送消息」快捷键，把网页「发送按键」改成一致 |
| 识别不准 / 漏识别 | 关键词用较长独特短语；缩小识别区域；调低识别频率(2s)；日志里可看每次识别原文 |
| 颜色识别没反应 | 确认已勾选启用；区域内非文字部分需有红/白/橙像素（其他颜色不识别，深色背景自动忽略）；文字区域会被自动排除；声音需先点击页面任意位置解锁；看「④」卡片内独立色块日志的采样数据 |
| 刷屏 | 调大「冷却时间」；颜色模块用「声音冷却」 |
| 监控时页面被降频 | Chrome 会节流后台标签页定时器，监控期间保持本页面可见（可放副屏/靠边） |
| 端口被占用 | `set PORT=8899` 后重新 `node server.js` |

## 目录结构

```
screen-qq-ocr\
├── server.js               # 本地服务（Node 零依赖）：静态页面 + /api/status + /api/send
├── qq-send.ps1             # QQ 自动发送脚本（选窗/激活/剪贴板/回车）
├── qq-list.ps1             # 枚举 QQ 窗口（JSON）
├── qq-common.ps1           # 共享 Win32 辅助（C# P/Invoke）
├── start.bat               # 一键启动
├── scripts\
│   ├── setup.ps1           # 初始化：下载 tesseract.js / 内核 / 中文模型
│   └── download.js         # Node 下载辅助（OpenSSL）
└── public\
    ├── index.html / style.css / app.js
    └── vendor\             # tesseract.js 库 + wasm 内核 + tessdata\chi_sim.traineddata.gz
```

## 隐私与安全

- 截屏、OCR、发送全部在本机完成，不经过任何第三方服务器。
- 发送动作会把 QQ 窗口切到前台（设计如此），发送后恢复原前台窗口。
- 「发送前倒计时」默认 3 秒，防止误触发。
